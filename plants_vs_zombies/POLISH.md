# 庭院界面与交互美化版

基于 GitHub main 提交 `26c322b`，保留 14 关、16 种植物、5 种僵尸、图鉴、铲子与暂停。

- 主菜单开始按钮重绘为带刻字、石材渐变、苔藓与叶片的石碑；统一选关和图鉴按钮材质。贴图以两倍分辨率绘制后缩小，字体保持原始宽高比例。
- 悬停时逐渐提亮并轻微抬起；按下时下沉，在原按钮范围内松开才进入。按下后移到外面松开可取消。Enter 仍然直接开始冒险。
- 卡片悬停有描边，种植时有短促回弹与落地光圈，阳光收集时显示星点和所得阳光。资源判定、攻击节奏和伤害数值保持原样。
- 支持 SDL 单指触摸：点击菜单、拖卡种植、拖铲移除、点收阳光。忽略系统合成的重复鼠标事件；失去焦点或窗口缩放会取消拖动。
- 植物贴图增加帧间过渡，透明边缘按预乘颜色插值；向日葵加入轻微、错相的连续摆动。种植位置、碰撞与攻击时机仍取原来的实体坐标。
- 暂停和图鉴会冻结植物与战斗反馈；菜单悬停反馈仍可使用。

已验证三种窗口尺寸下的鼠标与触摸事件路径、拖拽取消、反馈暂停、透明边缘与共享素材不被修改。14 关通关模拟及已有的图鉴、铲子、暂停、存档和种植测试通过。满草坪 45 株向日葵的无窗口渲染测试平均约 3.6 毫秒/帧；这不是实体触屏设备实测。

只运行植物大战僵尸测试：`python plants_vs_zombies/run_tests.py`。
