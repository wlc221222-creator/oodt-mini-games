# 八关冒险扩展

本次以《保卫萝卜》第一代为参考：天际、丛林、沙漠主题，每关15～25波，按关指定炮塔，三级升级，以及普通怪、飞行怪、厚血怪和末波巨怪的组合。八张路线与下列数值为本课程项目设计，并非逐关复制商业版。

保留用户指定的三血规则：每关3血，每只漏怪扣1血，第三只漏怪失败；进入下一关恢复3血。

共161波、1768只怪物。每关塔池包含前关塔池；炮塔数量由金币、建造与升级取舍决定，没有人为设置塔数上限。随关卡推进，怪物数量、生命与移动速度增加；同关后波生命也会增强。开局资金增加，让后关能够布置更多塔。前关金币不带入下一关，避免积蓄滚雪球抹平难度；积分、击杀数在连续挑战中累计。

## 炮塔机制

| 炮塔 | 对应原作能力 | 当前实现 |
| --- | --- | --- |
| 瓶子炮 | 基础快速单体输出 | 追踪弹，优先攻击更接近终点的范围内怪物 |
| 风扇 | 直线穿透 | 固定方向飞行，一发可命中多个怪物，每只只受一次穿透伤害 |
| 太阳 | 周身群攻 | 直接伤害塔周围范围内的全部怪物 |
| 星星 | 投弹、范围伤害 | 命中后造成区域溅射 |
| 冰冻星星 | 群体减速与伤害 | 命中区域减速，取最强减速，效果不叠乘 |
| 毒针 | 3～5秒持续毒伤 | 一至三级分别持续3、4、5秒，按实际剩余时间结算 |
| 火箭 | 穿透后末端爆炸 | 固定方向穿透，并在行程末端造成区域爆炸 |
| 雪花 | 周围怪物原地冻结 | 周身冰冻脉冲，冻结期间停止移动与行走动画 |

每座塔可升级两次至三级，攻击、间隔与射程随之提升，使用对应级别的原版动画；升级费见图鉴与操作面板。出售返还累计建造及升级支出的80%，不增加积分。战斗数值为三血制重新校准，不能当作商业原版精确数据表。

## 操作与保存

- `1`～`8` 或卡片选塔，左键空地建造，右键取消。未开放卡片显示开放关卡，不能提前购买。
- 点击已建炮塔查看当前级别、伤害、射程与间隔；`U` 或按钮升级，`Delete` 或按钮出售。
- `Tab` / 速度按钮切换1倍、2倍速；图鉴中的 `Tab` 切换炮塔与怪物，不改变战斗速度。
- `I` 查看图鉴，`P` 暂停；暂停、图鉴和菜单冻结战斗、状态计时及战斗动画。
- 主菜单 `L` 选择已开放关卡；选关左上角按钮或 `Esc` / `L` 返回。通关自动开放下一关，记录该关最佳剩余生命。失败可重试当前关。
- 源码存档：`defend_carrot/progress.json`；EXE存档：`%LOCALAPPDATA%/OODTMiniGames/DefendCarrot/progress.json`。只保存解锁和最佳通关成绩，进行中的战斗不保存。
- 与植物大战僵尸存档独立。进度文件已加入Git忽略，发布源码不包含个人进度。

## 界面展示

主菜单独立绘制天空与花草场景，沿用原版纹理、萝卜和怪物；加入标题描边、角色眨眼和摆动、漂浮光点与八种炮塔展示。菜单显示已开放及已守住关卡数。

选关页使用八张实际地图的缩略图，区分未开放、可挑战和最佳剩余血量；满血关卡使用金色边框。图鉴使用双栏手册和角色底座，怪物预览播放原版动作。暂停、胜利和失败使用不同的标题绶带、萝卜状态、成绩卡和提示。战斗卡片、操作区和按钮统一使用圆角、立体阴影、高光及悬停反馈，满级或金币不足的升级按钮显示灰色。

这些装饰使用独立的界面时钟，绘制不推进计时。菜单及图鉴预览的动作不会移动战场怪物、推进波次、计算伤害或改变存档；从图鉴返回暂停页仍保持暂停。

## 校准与验证

自动布塔策略调用真实购买、升级接口，仅使用开局、每波补给及击杀收入。完整跑完8关，建设与升级总投入从首关1680金币增至末关10200金币，场上塔数从6增至22。空置首关失败，仅放三座一级塔的末关防线也失败。此结果证明各关有可行解，不能代替不同玩家操作下的主观难度体验。

另覆盖塔池越级购买、波次重叠、穿透只命中一次、溅射、减速到期、中毒尾段计时、冰冻恢复、升级与出售、存档损坏恢复、八张路线连接及原版各级动画加载。界面测试还覆盖主菜单、选关鼠标返回、图鉴切页、三种结算按钮、重复绘制无副作用，以及界面动作与暂停战斗的时钟隔离。
